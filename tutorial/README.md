# OCaml Crash Course (Days 1-11)

This mirrors the tutorial track in `aoc2020_Prolog`, but the exercises here are reserved for OCaml.

## How to Use This Track
1. Work one day at a time in order.
2. Keep each day focused on one language concept or small puzzle-solving pattern.
3. Promote any durable AoC helpers into `src/common/` when they become broadly useful.
4. Run `dune runtest` after adding working examples or solve code.

## Daily Progression
- Day 1: values, expressions, bindings, and function definitions
- Day 2: lists, pattern matching, and recursion
- Day 3: records, variants, and result types
- Day 4: string parsing and lightweight I/O helpers
- Day 5: tail recursion and accumulators
- Day 6: sets, maps, and grid/state modeling
- Day 7: modules and signatures
- Day 8: folds, pipelines, and composition patterns
- Day 9: sorting, grouping, and counting patterns
- Day 10: memoization and performance measurement
- Day 11: AoC simulation dry run with parse/part1/part2/solve structure
